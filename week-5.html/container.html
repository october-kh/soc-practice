Using container

.container-{breakpoint}, which is width: 100% until the specified breakpoint
.container-fluid, which is width: 100% at all breakpoints

This is a simple container.

This is a fluid container. Width is 100% at all breakpoints.

This is a small container. Width is 100% until the small breakpoint (576px). When breakpoint is less than 576px, width is 100%.

This is a medium container. Width is 100% until the medium breakpoint (768px).

This is a large container. Width is 100% until the large breakpoint (992px).

This is an extra-large container. Width is 100% until the extra-large breakpoint (1200px).

This is an extra-extra-large container. Width is 100% until the extra-extra-large breakpoint (1400px).
